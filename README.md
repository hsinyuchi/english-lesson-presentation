# 🇹🇼 課堂互動簡報技能 (English Lesson Presentation Skill)

> 一鍵將英文課文轉為單一 HTML 互動簡報，具備句子拆解、大考 7000 單分級滑桿、iPad Freeform 無邊際板書、深淺色切換、聚光燈、Mission 1 心智圖與 Mission 2 素養測驗。

## ⚡ 快速使用方式 (How to Use)

### 🅰️ 方式一：AI Agent / CLI 一鍵安裝
1. 下載獨立安裝包 [`Skill_02_English_Lesson_Presentation.zip`](https://b1-english-hub.pages.dev/Skill_02_English_Lesson_Presentation.zip)。
2. 解壓縮後將 `english-lesson-presentation` 資料夾放入您的 AI Agent 技能目錄（如 `~/.gemini/config/skills/` 或 Antigravity 技能路徑）。
3. 在對話框直接調用：
   > 「請使用 `english-lesson-presentation`，幫我處理這篇課文：[貼上英文課文]」

---

### 🅱️ 方式二：一般網頁版 AI（ChatGPT / Claude / Gemini）兩步驟交握法
1. 打開 [`SKILL.md`](SKILL.md)，複製全文貼入對話框，最後附上：
   > 「請仔細閱讀以上規範。如果你完全理解所有架構與功能，請只回覆我：**『報告老師，專家已就緒！請提供您的英文課文。』**，先不要生成任何程式碼。」
2. 收到 AI 確認後，直接貼上英文課文即可！
