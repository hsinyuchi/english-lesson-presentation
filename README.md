### 🌟 專案簡介 (Overview)
本技能庫專為臺灣普通型高中、技術型高中（普高 / 技高）英文科教師打造。能將**任意英文課文、素養短文、時事新聞或大考閱讀篇章**，一鍵全自動轉換為具備**「一頁一句精讀、108課綱7000單字彈出卡、原音朗讀、心智圖結構導讀、5題閱讀素養測驗與黑板互動工具箱」**的單一獨立 HTML5 教學簡報網頁！

1. **🚫 零滾動單頁自適應 (Zero-Scroll Auto-Fit Screen)**：
   - 86" IFP 大螢幕、投影機或 iPad 螢幕絕不產生垂直捲軸，字體自動等比放大 (`clamp`)。
2. **🖍️ 物理透光不遮字螢光筆 (Translucent Highlighter)**：
   - 淺色模式採用 `mix-blend-mode: multiply`（正片疊底），黑色英文字永遠浮在螢光墨水上方，文字 100% 清晰絕不遮字！
   - 深色模式採用 `mix-blend-mode: screen`（透光濾色），白色文字維持極致純白。
3. **🔲 幾何形狀框選標記 (Geometric Shapes • S)**：
   - 長方形 (🔲)、圓形 (⭕)、箭頭 (➡️)、直線 (➖) 搭配 5 色調色盤與實時拖曳預覽。
4. **📝 重點彩色便箋 (Floating Sticky Notes • N)**：
   - 4 款粉彩便箋（黃、綠、藍、粉），自由拖曳、可打字筆記、各頁獨立記憶、自動合成進匯出講義！
5. **⏱️ 課堂活動計時器 (M) ＆ 🎲 隨機抽籤點名 (R)**：
   - 內建 1/3/5/10 分鐘計時與座號轉盤，右上角與底部皆附有醒目實體 `✕` 觸控關閉按鈕。
6. **📦 智慧自選頁面講義匯出引擎 (Selective Export Engine)**：
   - 自由勾選匯出頁面，具有手寫筆跡或便箋的頁面自動標註 `✏️ 含有手寫筆記` 徽章，匯出高畫質 PDF / PNG ZIP。

### 📦 安裝與使用指南 (How to Install & Use)

#### 方式 1：給 AI Coding Assistant (Antigravity / Cursor / Claude Code)
將本倉庫下載解壓縮後，複製 `SKILL.md` 到您的 Skill 資料夾：
```bash
# Windows
copy SKILL.md C:\Users\<YourUsername>\.gemini\config\skills\english-lesson-presentation\SKILL.md
```

#### 方式 2：直接使用對話 Prompt 生成
在 AI 對話框輸入：
> 「請使用 `english-lesson-presentation` 技能，將以下英文課文製作成 v7 旗艦多模態互動教學簡報網頁：[貼上英文課文]」
